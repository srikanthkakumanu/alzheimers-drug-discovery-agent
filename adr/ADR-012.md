# ADR-012 — Python 3.12 with uv and ruff

**Status: accepted** 2026-11-09 — selected by the project owner during stack review · type: `language-and-tooling`

## Context
The LLM and agent ecosystem is strongest in Python, and the repository validator already implements record parsing and scoring in Python.

## Decision
Use Python 3.12, uv for locked dependencies (`uv.lock`), and ruff for linting and formatting.

## Alternatives
| Option | Tradeoff |
| --- | --- |
| Python + Java/Spring API | Robust enterprise service layer, but two stacks from day one. |
| TypeScript/Node | One language with a web UI, but rewrites existing checks and has a thinner scientific ecosystem. |

## Consequences
One language for tools and application; reproducible installs. Repository checks stay standard-library only so they run without installing dependencies.

## Validation
CI runs `uv sync --frozen`, ruff, and the test suite on Python 3.12.

## Revisit
If a separate service layer is required, or Python 3.12 leaves its support window.
