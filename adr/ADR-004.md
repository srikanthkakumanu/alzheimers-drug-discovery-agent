# ADR-004 — Document-defined roles before automated orchestration

**Status: proposed** — awaiting owner review · type: `orchestration-architecture`

## Context
Role files and Claude skills exist, but no application orchestrator, shared run state, or registered research subagents exist. The user wants a documentation review before implementation.

## Decision
Document researcher, reviewer, planner, regulatory, and portfolio responsibilities now. Propose a bounded sequential coordinator for later implementation. Keep handoffs evidence-linked and make human decisions explicit; do not equate folders or slash commands with running agents.

## Alternatives
| Option | Tradeoff |
| --- | --- |
| Autonomous parallel agent team | May increase coverage, but adds duplicate retrieval, coordination, and uncontrolled cost. |
| One unconstrained prompt | Lower setup cost, but obscures evidence checking and decision ownership. |

## Consequences
The current repository remains inspectable without a runtime. Future orchestration can reuse role contracts, but implementing state, budgets, tool permissions, and recovery remains necessary.

## Validation
Review the proposed transitions and role I/O in the agent design. Existing native metadata tests do not validate future agent behavior.

## Revisit
Choose orchestration technology only after requirements, transition rules, and evaluation cases are reviewed.

**Update 2026-11-09:** the owner selected LangGraph as the coordinator ([ADR-014](ADR-014.md)). The decision’s intent is unchanged: explicit bounded transitions, deterministic nodes outside the model, evidence-linked handoffs, human decision as an interrupt.
