# ADR-011 — Typer CLI as the first interface

**Status: accepted** 2026-11-09 — selected by the project owner during stack review · type: `interface`

## Context
Users are a small expert team reviewing synthetic and public evidence. A web UI would add hosting, authentication, and frontend work before the core review flow is proven.

## Decision
Build a Typer command-line tool that prints a Markdown decision packet (commands in the [application design](../docs/architecture/application-design.md)). Keep the Claude Code skills as authoring aids.

## Alternatives
| Option | Tradeoff |
| --- | --- |
| Internal web app | Better for non-technical owners and multi-user review, but adds auth, hosting, and UI up front. |
| Slack/Teams chat | Convenient, but weak for tables, packets, and audit trails. |

## Consequences
Fast first slice with no hosting. Non-technical owners need someone to run commands or read exported packets.

## Validation
Packets render for EV-02–EV-13; exit codes follow the CLI spec.

## Revisit
When multi-user review or non-technical owners become primary users.
