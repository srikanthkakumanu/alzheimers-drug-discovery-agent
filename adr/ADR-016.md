# ADR-016 — Files plus SQLite for storage

**Status: accepted** 2026-11-09 — selected by the project owner during stack review · type: `data-architecture`

## Context
Evidence must stay reviewable in git; runs, checkpoints, and human decisions need transactional local storage.

## Decision
Keep Markdown/JSON records in git as the source of truth. Store run logs, human decisions, and the FTS5 index in `var/neuroquest.sqlite3` and LangGraph checkpoints in `var/checkpoints.sqlite3` (both git-ignored). Schema: [application design](../docs/architecture/application-design.md).

## Alternatives
| Option | Tradeoff |
| --- | --- |
| Files + PostgreSQL | Better concurrency, but needs a server now. |
| Everything in PostgreSQL | Strong querying, but loses git review of evidence. |

## Consequences
No servers; easy inspection. Single-writer concurrency; multi-user use would need a server database.

## Validation
Migration tests create the schema from scratch; decisions survive restart in Docker via a volume.

## Revisit
When concurrent users or remote access are required.
