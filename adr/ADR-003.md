# ADR-003 — Layered progressive context disclosure

**Status: accepted** 2026-11-09 — accepted by the project owner before implementation · type: `context-architecture`

## Context
Most research questions need a small subset of the evidence. Every byte in always-loaded instructions is paid on every turn, and bulk-loaded archives make unrelated or stale claims more prominent. Claude Code loads the root `CLAUDE.md` at startup and a subdirectory’s `CLAUDE.md` only when files in that directory are read.

## Decision
Organize context into explicit layers, each loaded only when the layer above routes to it:
- **L0** root `CLAUDE.md`: non-negotiable rules and a router (≤3,200 bytes).
- **L1** `TASK.md` and `STATUS.md`: the current question and phase.
- **L2** one role contract or skill.
- **L3** one directory `README.md` index to select IDs.
- **L4** at most 3 records per batch; directory-specific reading and editing rules live in that directory’s `CLAUDE.md` so they load only with those records.

Design documents live under `docs/` and are reference material outside the default path. Use ordinary links, never `@` imports. Phase and status are stated once, in `STATUS.md`.

## Alternatives
| Option | Tradeoff |
| --- | --- |
| Single large instruction file | Simple, but every task pays for unrelated detail |
| Record rules in root `CLAUDE.md` | Always available, but paid on every turn including design-only tasks |
| Vector retrieval immediately | May help at scale, but adds indexing, provenance, and evaluation work before it is needed |

## Consequences
Small default context and explicit evidence selection. Indexes and directory rules must be kept in sync with primary records; token estimates from bytes are approximate; skill descriptions, tool schemas, and conversation history add cost outside these files.

## Validation
The validator enforces file-size budgets per layer. Later, measure actual provider token usage per task and retrieval relevance on the evaluation set.

## Revisit
When indexed lookup repeatedly misses needed evidence, when the corpus outgrows file indexes, or when measured retrieval quality justifies a search layer.
