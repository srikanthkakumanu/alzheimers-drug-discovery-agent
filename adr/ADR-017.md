# ADR-017 — Index lookup plus SQLite FTS5 retrieval

**Status: accepted** 2026-11-09 — selected by the project owner during stack review · type: `retrieval-architecture`

## Context
The corpus is small, and every claim must be attributable to a record ID.

## Decision
Resolve exact IDs from directory indexes and search record text with SQLite FTS5. Tavily web search is listed, disabled, in `config/mcp.json`; if enabled later, its results are leads to verify in PubMed or Europe PMC, never citable evidence.

## Alternatives
| Option | Tradeoff |
| --- | --- |
| Vector search now | Semantic recall at scale, but adds embeddings, indexing, and evaluation. |
| Live PubMed lookup | Fresher evidence, but adds rate limits and verification work. |

## Consequences
Precise, cheap, attributable retrieval; may miss paraphrased matches.

## Validation
Retrieval finds the expected records for each evaluation scenario.

## Revisit
When indexed search repeatedly misses needed evidence on the evaluation set.
