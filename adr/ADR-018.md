# ADR-018 — LangSmith tracing with pytest evaluation

**Status: accepted** 2026-11-09 — selected by the project owner during stack review · type: `observability`

## Context
Graph runs need step-level traces, token and cost visibility, and repeatable evaluation datasets.

## Decision
Trace LangGraph and OpenAI calls with LangSmith (tracing off by default; `LANGSMITH_TRACING`). Keep evaluation scenarios as pytest tests and mirror them as a LangSmith dataset. Compute cost from OpenAI usage data.

## Alternatives
| Option | Tradeoff |
| --- | --- |
| Local JSON logs only | Private and free, but no trace UI. |
| Self-hosted Langfuse | Keeps data in-house, but adds a service to operate. |

## Consequences
Rich traces with little setup; prompts and outputs go to a third party, acceptable only for synthetic and public data.

## Validation
Every run records a trace ID; evaluation results are reproducible from the dataset.

## Revisit
Before private data (masking or self-hosting), or if cost or terms change.
