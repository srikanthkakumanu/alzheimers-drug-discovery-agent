# ADR-014 — LangGraph as the run coordinator

**Status: accepted** 2026-11-09 — selected by the project owner during stack review · type: `orchestration-architecture`

## Context
[ADR-004](ADR-004.md) requires explicit, bounded transitions with deterministic steps outside the model and a human decision point.

## Decision
Implement the run as a LangGraph `StateGraph`: deterministic nodes (scope, load, score and gate, budget) plus LLM role nodes; typed `TypedDict` state holding Pydantic models; SQLite checkpointer; `interrupt()` for the human decision ([agent design](../docs/architecture/agent-design.md)).

## Alternatives
| Option | Tradeoff |
| --- | --- |
| Own state machine | Fewest dependencies, but checkpointing and resume must be hand-built. |
| Agent SDK runtime | Less code, but less explicit control of transitions. |

## Consequences
Checkpointing and pause/resume come built in; adds a framework dependency whose upgrades must be tracked.

## Validation
Graph tests with a fake LLM cover every edge, including block, partial, and resume.

## Revisit
If LangGraph constraints block a required transition or upgrades become costly.
