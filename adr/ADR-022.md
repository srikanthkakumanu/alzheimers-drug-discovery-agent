# ADR-022 — Low-cost LLM providers via OpenAI-compatible endpoints

**Status: accepted** 2026-11-09 — chosen by the project owner before the first live run · type: `integration-architecture` · supersedes [ADR-015](ADR-015.md)

## Context
NeuroQuest is a learning project for harness engineering, multi-agent orchestration, and layered context. The owner wants LLM cost kept minimal and already holds Groq, Google Gemini, and Mistral API keys. All three expose OpenAI-compatible Chat Completions endpoints, so the existing `openai` SDK can reach them by changing the base URL.

## Decision
Model IDs carry a provider prefix (`groq:`, `google:`, `mistral:`); a bare ID still means OpenAI. `llm/compat_client.py` calls Chat Completions in JSON mode, puts the Pydantic schema in the system prompt, validates every reply, and allows one repair. Default tiers: economical `groq:llama-3.1-8b-instant`, capable `google:gemini-2.5-flash-lite`, escalation `mistral:mistral-small-latest`. Model IDs and prices stay configuration (`.env`), and the $0.10 per-run cap still applies, priced at paid-tier rates as an upper bound. The OpenAI Responses client from ADR-015 remains for bare IDs. Send only synthetic and public content.

## Alternatives
| Option | Tradeoff |
| --- | --- |
| Keep OpenAI (ADR-015) | Native Structured Outputs, but higher cost than the owner wants. |
| Provider SDKs (groq, google-genai, mistralai) | Native features per provider, but three dependencies and three code paths. |
| LiteLLM or LangChain chat models | One interface, but an extra layer that hides the call details this project exists to learn. |

## Consequences
JSON mode guarantees JSON syntax, not schema conformance, so validation and repair carry more weight than with Structured Outputs; small models may need the repair attempt more often. Prompt caching varies by provider; `cached_tokens` is recorded when reported. Prompts leave the machine under each provider's API terms; free tiers may use prompts for training, which is acceptable only for synthetic and public content.

## Validation
Offline tests cover routing, JSON parsing, fence stripping, and repair. The first live run of A G N stays within budget, keeps N blocked, and cites only real record IDs; EV-01–EV-13 as in the [evaluation plan](../docs/delivery/evaluation-plan.md).

## Revisit
If schema failures persist after repair, on material price or free-tier change, or before any non-public data.
