# ADR-021 — Python 3.13 runtime with uv and ruff

**Status: accepted** 2026-11-09 — chosen by the project owner at implementation start · type: `language-and-tooling` · supersedes [ADR-012](ADR-012.md)

## Context
ADR-012 selected Python 3.12. At implementation start the owner chose Python 3.13. The machine’s system interpreter is 3.15, which some compiled dependencies may not yet support; uv can install a pinned interpreter per project.

## Decision
Pin Python 3.13 (`.python-version`, `requires-python = ">=3.13,<3.14"`, Docker `python:3.13-slim`). Keep uv with a committed `uv.lock` and ruff for lint and format, as in ADR-012. Repository checks (`scripts/`, `tests/test_*.py`) stay standard-library only and run on any Python ≥3.10.

## Alternatives
| Option | Tradeoff |
| --- | --- |
| Python 3.12 (ADR-012) | Longest library track record, but older than the owner’s preference. |
| Python 3.15 (system) | No interpreter download, but higher risk of missing wheels for compiled dependencies. |

## Consequences
Modern syntax (PEP 695 generics, `type` aliases) is available. uv downloads 3.13 automatically for development; CI and Docker use the same version.

## Validation
`uv sync --frozen`, `ruff`, `mypy --strict`, and `pytest` pass on 3.13; the Docker image builds and runs `neuroquest --help`.

## Revisit
When 3.13 approaches end of support, or a required dependency drops it.
