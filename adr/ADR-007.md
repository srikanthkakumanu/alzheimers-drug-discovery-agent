# ADR-007 — Indexed durable memory and relative scenario history

**Status: proposed** — awaiting owner review · type: `memory-architecture`

## Context
Full session transcripts are expensive context and may preserve stale or sensitive detail. Existing month files describe a fictional sequence, not real dates or completed work.

## Decision
Keep root and role memory as compact indexes of durable implications. Store detailed fictional history in the twelve relative periods and primary observations in experiment records. Separate these files from Claude machine-local auto memory.

## Alternatives
| Option | Tradeoff |
| --- | --- |
| Append every conversation to root memory | Preserves detail but increases context cost and stale-claim exposure. |
| Discard prior failures | Keeps files small but removes the reason for future stop conditions. |

## Consequences
Relevant history remains discoverable with limited routine context. Summaries need maintenance, and the original monthly filenames need an explicit relative-period explanation.

## Validation
Check links, provenance, and calendar_mapping. Human review must ensure a memory statement still agrees with its primary record.

## Revisit
Reconsider retention and access policy before real private data or a persistent runtime is introduced.
