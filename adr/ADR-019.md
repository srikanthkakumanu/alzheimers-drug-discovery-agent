# ADR-019 — Docker for packaging and runs

**Status: accepted** 2026-11-09 — selected by the project owner during stack review · type: `deployment`

## Context
Runs must be repeatable on reviewer machines and in CI without leaking secrets into images.

## Decision
Ship a `python:3.13-slim` image (per [ADR-021](ADR-021.md)) built with uv, running as a non-root user. Mount records read-only, persist `var/` on a volume, pass secrets at runtime with `--env-file`, and exclude `.env` through `.dockerignore`. Runbook: [application design](../docs/architecture/application-design.md).

## Alternatives
| Option | Tradeoff |
| --- | --- |
| Local install only | Simplest, but environments drift. |
| Cloud service | Shared access, but needs auth and operations first. |

## Consequences
Repeatable runs and a path to a server; adds a Docker prerequisite.

## Validation
Image builds in CI; a smoke run completes with a fake LLM and no network.

## Revisit
When a shared deployment is required.
