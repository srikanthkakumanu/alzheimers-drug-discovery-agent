# Evidence-gated roadmap

Illustrative sequence; no dates or commitments agreed. Each milestone starts only when the previous gate is met. Current position: [STATUS.md](../../STATUS.md).

| # | Milestone | Deliverable | Gate to proceed |
| --- | --- | --- | --- |
| 1 | Design baseline | Scope, requirements, architecture, proposed ADRs, contracts, synthetic corpus | Repository internally consistent — **done** |
| 2 | Owner review | Accepted / revised / rejected decisions; open questions closed | Owner dispositions recorded ([TASK.md](../../TASK.md)) |
| 3 | Implementation planning | Selected stack, budget, evaluation set, first slice | Explicit instruction to implement |
| 4 | First slice | Synthetic question → decision packet, with deterministic scoring and gates | Passes agreed evaluation scenarios |
| 5 | Integration expansion | One justified real source at a time (e.g. literature lookup) | Tool contract, governance, and evaluation accepted per source |
| 6 | Operational use | Deployment, access control, support model | Measured reliability, security, and quality reviewed |

The original skeleton’s 2027–2029 discovery/IND dates were not backed by a sponsor plan and are not retained. Real therapeutic development needs a separately qualified program. Detail: [implementation plan](../delivery/implementation-plan.md).
